# KnowledgeVault Backend

Minimal FastAPI scaffold for Sprint 1. Demonstrates the chosen framework
and project layout only — ingestion, embeddings, and search are built
incrementally starting in Sprint 1 (see the Roadmap in the Vision doc).

## Setup

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

The API will be available at `http://localhost:8000`. Interactive docs
(Swagger UI) are auto-generated by FastAPI at `http://localhost:8000/docs`.

## Endpoints

- `GET /health` - returns service status, for confirming the app is running.
- `POST /upload` - placeholder upload endpoint; accepts a file and echoes
  back its name, content type, and size. Real text extraction lands in
  Sprint 1.
