# KnowledgeVault Backend

FastAPI project scaffold (KV-5). Proves the framework and layout work.
The upload endpoint (KV-6) and data model (KV-7) build on top of this.

## Setup

```bash
cd backend
python -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

The API runs at `http://localhost:8000`. Interactive docs (Swagger UI)
are auto-generated by FastAPI at `http://localhost:8000/docs`.

## Verify it works

```bash
curl http://localhost:8000/health
```

Should return something like:
```json
{"status": "ok", "service": "knowledgevault-backend", "timestamp": "..."}
```
